# Ordning

The `Ordning` application was originally developed as a tool to bring order to the invoice generation of a small but very fast-growing venture within software development consulting.

This desktop application supports both Linux (and Windows). The data is stored locally as a standard sqlite database, enabling the user to migrate the data to some other format of his/hers choosing later on.

The application is free to use, and no registration is needed.

## Features

The application provides a simple user interface for working with:

- company information and branding
- customers and customer references
- agreements and contract data
- invoice drafts and finalized invoices
- PDF invoice generation

## Limitations

It is currently only generating a Swedish invoice, i.e. faktura.
